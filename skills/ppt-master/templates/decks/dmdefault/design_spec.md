# Dameng Default Corporate Template - Design Specification

## I. Template Overview

| Property | Description |
| --- | --- |
| **Template Name** | dmdefault |
| **Display Name** | Dameng Default Corporate Template |
| **Use Cases** | 售前技术交流、数据库解决方案汇报、产品发布与运维答辩 |
| **Design Tone** | Clean, data-driven, tech-accented, authoritative |
| **Theme Mode** | Light theme (white background with deep blue and red highlight accents) |

This template is refined from the official Dameng presentation theme.

## II. Color Scheme

| Role | Color Value | Usage |
| --- | --- | --- |
| **Background** | `#FFFFFF` | Core slide background (lt1) |
| **Secondary Background** | `#F3F4F8` | Contrast container panels (lt2) |
| **Primary Theme Blue** | `#003EEE` | Main accents, headers, and highlights (accent4) |
| **Accent Red** | `#EC1B34` | Data highlighting, alerts, and critical indicators (accent3) |
| **Dark Accent Blue** | `#0000D2` | Strong accents and secondary structural colors (accent1) |
| **Body Text** | `#020202` | Main titles and active labels (dk1) |
| **Secondary Text** | `#595959` | Explanations, captions, and muted labels (dk2) |

## III. Signature Design Elements

1. **Brand Contrast Palette**: High-contrast layout using Dameng Tech Blue (`#003EEE`) for structure and accent Red (`#EC1B34`) for data callouts.
2. **Clean Typography Frame**: Optimized layout utilizing `Poppins` and `HarmonyOS Sans SC` for modern sans-serif visual balance.
3. **Structured Content Area**: Adapts adapted layout with a blank viewport and content watermark, ensuring high flexibility for card-based details.
